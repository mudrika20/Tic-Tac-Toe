# 🎮 Tic Tac Toe Game (React + Vite)

## 🌐 Live Demo
🚀 [Play Now](https://mudrika20.github.io/Tic-Tac-Toe/)

---

## 📌 Description
This is a simple and interactive Tic Tac Toe game built using React and Vite.  
It allows two players to play turn-by-turn with automatic winner detection and a clean UI.

---

## 🚀 Features
- 👥 Two-player gameplay
- 🔁 Turn-based system (X and O)
- 🏆 Automatic winner detection
- 🤝 Tie detection
- 🔄 Play again option
- 🎨 Color-based UI for better experience
- ⚡ Fast performance using Vite

---

## 🛠️ Technologies Used
- React (useState, useEffect)
- Vite
- JavaScript (ES6)
- HTML5 & CSS3

---

## 📂 Project Structure

src/
├── Game.jsx # Handles game logic and board
├── Result.jsx # Displays winner or tie
├── UserInfo.jsx # Takes player names
